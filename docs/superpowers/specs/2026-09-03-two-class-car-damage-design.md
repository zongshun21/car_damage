# YOLO26s 两分类车身缺陷训练设计

## 目标

将现有 `dent / crack / scratch` 三分类任务调整为 `dent / scratch` 两分类任务，在保持原始训练集与验证集划分不变的前提下，以独立验证集 mAP50 不低于 65% 为目标，并保留适合笔记本本地推理的 YOLO26s。

## 数据转换

- 原始数据集只读，不删除或覆盖任何图片及标签。
- 在 `.runtime/two_class_dataset` 创建派生数据集，图片优先使用硬链接以避免重复占用空间。
- 保留原类别 `0 dent`，删除原类别 `1 crack`，将原类别 `2 scratch` 映射为新类别 `1 scratch`。
- 只含 crack 的图片保留为空标签背景样本，防止数据划分发生变化。
- 同时转换 train 和 val，确保两边类别定义完全一致；验证集不复制、不增强。
- 转换过程中剔除零面积框，并检查图片与标签一一对应。

## 训练与选择

- 从当前最佳三分类 YOLO26s 权重迁移可复用特征，检测头适配为两个类别。
- 使用 768 输入、Windows 稳定配置 `batch=32, workers=0`。
- 先运行 1 epoch 冒烟训练，确认数据加载、类别映射、显存和验证流程正常。
- 正式训练使用早停；只依据原验证划分的 mAP50/mAP50-95 选择 `best.pt`。
- 若迁移微调未达到目标，则自动比较从官方本地 `yolo26s.pt` 初始化的训练方案，不通过修改验证集提高分数。

## 验证与交付

- 独立运行验证，报告 overall、dent、scratch 的 Precision、Recall、mAP50 和 mAP50-95。
- 用真实图片执行一次端到端推理冒烟测试。
- 提供两分类专用权重和 PowerShell 一键推理脚本。
- 成功标准是独立验证 mAP50 ≥65%；若未达到，保留实际最佳结果并明确瓶颈。
