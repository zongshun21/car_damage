# 11 常见错误排查

排错原则是先确认当前目录和环境，再看完整报错的第一处，而不是只看最后一行。

## 1. `conda` 不是命令

说明 Miniconda 尚未安装，或当前 PowerShell 没有加载 Conda。安装 Miniconda 后重新打开 **Anaconda PowerShell Prompt**，也可执行：

```powershell
conda init powershell
```

关闭并重新打开终端后再试。

## 2. PowerShell 禁止运行脚本

仅对当前窗口临时放行：

```powershell
Set-ExecutionPolicy -Scope Process Bypass
```

这个设置在关闭窗口后失效，不会永久降低系统策略。

## 3. `torch.cuda.is_available()` 是 `False`

先运行：

```powershell
nvidia-smi
conda run -n dl python -c "import torch; print(torch.__version__, torch.version.cuda, torch.cuda.is_available())"
```

如果 `nvidia-smi` 不存在或报错，先安装/更新 NVIDIA 驱动。如果 PyTorch 版本带 `+cpu`，说明装成了 CPU 版；重新运行本项目的 GPU 环境脚本。CUDA Toolkit 通常不需要另装，PyTorch wheel 已包含所需运行库，但显卡驱动必须可用。

## 4. 显存不足或 `CUDA out of memory`

训练时优先依次尝试：

1. 将 `batch` 从 10 降为 8、4 或 2；
2. 将 `imgsz` 从 768 降到 640；
3. 关闭占显存的软件和其他训练进程；
4. 确认没有重复启动训练。

降低 batch 通常不会导致训练失效，但可能需要更长时间。推理时一次处理一张图，显存需求通常小得多。

## 5. 首次训练为什么下载 `yolo26s.pt`

`yolo26s.pt` 是官方预训练起点，不是你的最终车损模型。迁移学习从通用视觉特征开始，通常比完全随机初始化收敛更快。训练结束后生成的 `best.pt` 才是结合车损数据得到的权重。若电脑离线，请提前把官方起始权重放在项目根目录，并在配置中指向它。

## 6. 数据集路径或 YAML 报错

先检查当前目录是否为项目根目录，再运行：

```powershell
conda run -n dl python scripts/check_dataset.py --data configs/data.yaml
```

常见原因包括：YAML 中路径拼错、图片没有同名标签、标签类别超出范围、复制数据时漏了目录。项目配置通过相对路径和路径解析器处理，不应手工写开发者电脑的绝对路径。

## 7. 图片和标签数量不完全相等

没有目标的背景图片允许对应一个空 `.txt` 标签，所以“空标签”本身不一定是错误。真正有问题的是图片没有标签文件、标签没有图片、行不是五列、坐标超出 `0~1`，或类别编号超出 `names` 范围。以检查脚本的 `errors` 为准；警告要结合图片人工复核。

## 8. GUI 无窗口或一直卡住

优先使用：

```powershell
.\check_gui_env.ps1 -EnvName dl
.\start_gui.ps1 -EnvName dl
Get-Content "$env:LOCALAPPDATA\LZPU\CarDamagePlatform\startup.log" -Tail 30
```

普通 SSH 没有可见桌面，无法展示 GUI，请换成本地桌面或远程桌面。`SetProcessDpiAwarenessContext() failed` 多数是 Windows/远程会话的 DPI 提示，启动脚本已做兼容处理；应结合启动日志判断是否还有真正的异常。

## 9. 模型下拉框为空

确认以下文件同时存在：

```text
models/models.json
models/YOLO26s_DentScratch_mAP50_73.18.pt
models/YOLO26s_DentCrackScratch_mAP50_53.10.pt
```

不要只复制 `models.json`。如果自行改文件名，也必须同步更新清单中的 `filename`。

## 10. 没有检测框或误检很多

先确认选择了正确模型。然后用验证集图片测试，并逐步调节置信度：漏检多就降低，误检多就提高。如果只在新场景表现差，通常属于数据分布变化，例如光线、距离、车漆颜色或拍摄角度不同；此时应补充该场景的标注数据并微调，而不是无限降低阈值。

## 11. 标注仍显示英文

仓库 GUI 已在绘图阶段将三类转换为中文。若仍显示英文，通常是运行了 Ultralytics 自带 CLI 输出、旧版发布目录，或打开了先前生成的结果图。重新启动本仓库最新版 GUI，并重新执行检测。

## 12. 如何获得可复现的错误信息

提交问题时附上：操作系统、显卡型号、`python --version`、PyTorch/Ultralytics 版本、执行的完整命令，以及从第一处异常开始的完整文本。不要只发“不能运行”，也不要上传包含用户名、密钥或私人图片的日志。
