# 08 图片推理与结果分析

## 本章目标

使用仓库内置或自己训练的权重检测单张图片和文件夹，理解输出目录、阈值和 CPU/GPU 选择。

## 1. 使用推荐模型快速推理

```powershell
conda activate car_damage_yolo26
.\run_inference.ps1 -Source "你的图片.jpg"
```

检测文件夹：

```powershell
.\run_inference.ps1 -Source "D:\car_images"
```

脚本默认使用：

```text
models/YOLO26s_DentScratch_mAP50_73.18.pt
```

默认输出目录：

```text
runs/car_damage/predict_two_class/
```

## 2. 常用覆盖参数

```powershell
.\run_inference.ps1 `
  -Source "D:\car_images" `
  -Weights "runs/car_damage/yolo26s_two_class_768/weights/best.pt" `
  -Device 0 `
  -Confidence 0.35 `
  -ImageSize 768 `
  -Output "runs/my_prediction"
```

- `Source`：单张图片或只包含图片的目录。
- `Weights`：模型权重路径。
- `Device`：`0` 为第一张 NVIDIA GPU，`cpu` 为处理器。
- `Confidence`：保留预测框的最低置信度。
- `ImageSize`：送入模型的尺寸。
- `Output`：结果目录。

## 3. 直接使用 Python 脚本

```powershell
python scripts/predict.py `
  --weights models/YOLO26s_DentScratch_mAP50_73.18.pt `
  --source "D:\car_images" `
  --device 0 `
  --conf 0.25 `
  --iou 0.70 `
  --imgsz 768 `
  --output runs/car_damage/predict `
  --save-txt `
  --save-conf
```

`--save-txt` 保存 YOLO 格式预测文本，`--save-conf` 在每行末尾追加置信度，适合后续统计。命令行脚本使用 Ultralytics 默认绘图；GUI 使用项目自己的中文绘图。

## 4. 阈值怎样调

从 `conf=0.25` 开始：

- 误报太多：尝试 0.35、0.45。
- 漏检太多：尝试 0.20、0.15，并人工确认新增框是否合理。
- 同一缺陷重复框较多：适当降低 IoU NMS 阈值。

不要针对一两张图片调到满意后就声称模型提高了。阈值应在一批有代表性的图片上比较。

## 5. 推理速度怎么读

首次推理通常包含模型加载和 GPU 预热，会慢于后续图片。GUI 显示的 ms/张和 FPS 更适合观察同一次批量任务中的平均速度。

本项目曾在 RTX 4090 上测得 GUI 后端稳定约 54.3 ms/张，在 CPU 上约 317.1 ms/张。不同图片、驱动、电源模式和设备会产生明显差异，这不是所有机器的速度承诺。

## 6. 看不到检测框怎么办

依次检查：

1. 权重是否对应两分类任务。
2. 图片缺陷是否属于 dent/scratch。
3. `conf` 是否过高。
4. 图片是否过暗、模糊或与训练分布差异很大。
5. 使用验证集已知正样本测试，区分程序问题和泛化问题。

## 成功标准

输出目录中出现带框图片，终端没有权重或输入路径错误。下一步阅读 [09 GUI 平台原理与封装](09_GUI平台原理与封装.md)。
